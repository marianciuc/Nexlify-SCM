# ESLint и Prettier конфигурация

Этот проект настроен с ESLint и Prettier для поддержания качества кода.

## Скрипты

### Линтинг

- `pnpm lint` - проверить код с ESLint
- `pnpm lint:fix` - автоматически исправить проблемы ESLint

### Форматирование

- `pnpm format` - отформатировать код с Prettier
- `pnpm format:check` - проверить соответствие форматированию

### Проверка типов

- `pnpm typecheck` - проверить TypeScript типы

## Автоматизация

### Pre-commit hooks

Настроен pre-commit hook с помощью Husky, который автоматически запускает:

- ESLint с автоисправлением
- Prettier форматирование

### VS Code

Конфигурация VS Code настроена для:

- Автоматического форматирования при сохранении
- Автоматического исправления ESLint ошибок при сохранении

## Правила ESLint

### TypeScript

- Предупреждения для `any` типов
- Запрет неиспользуемых переменных (кроме начинающихся с `_`)

### React

- React 19 совместимость
- Поддержка JSX без импорта React
- Предупреждения для компонентов без Fast Refresh

### Импорты

- Автоматическая сортировка импортов
- Группировка импортов по типам
- Алфавитная сортировка

### Общие правила

- Предупреждения для `console` statements
- Запрет `debugger`
- Предпочтение `const` над `let`

## Prettier настройки

- Точка с запятой: включена
- Одинарные кавычки: включены
- Максимальная ширина строки: 100 символов
- Отступы: 2 пробела
- Trailing commas: ES5 совместимые

## Игнорируемые файлы

### ESLint

- `dist/`, `build/`, `node_modules/`
- Сгенерированные файлы: `routeTree.gen.ts`, `api.ts`

### Prettier

- То же самое + конфигурационные файлы
- Файлы блокировки пакетных менеджеров
